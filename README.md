# GlycoTwin AI: A Personalized Digital Twin for Predicting Glucose Excursions

**Institution:** Amrita Vishwa Vidyapeetham, Chennai Campus  
**Team members:** Pavithra N and Methra Renganathan

## 1. Project Overview

GlycoTwin AI is a healthcare AI prototype exploring glucose monitoring through a digital-twin-inspired workflow. It demonstrates synthetic patient profiles, glucose timelines, a dashboard, and experimental glucose-risk predictions.

## 2. Problem Statement

Glucose levels fluctuate in response to physiological and lifestyle factors. Understanding glucose patterns over time is an important research direction for personalized diabetes care. This prototype explores a software workflow for visualizing glucose history and investigating potential glucose excursions.

## 3. Healthcare Use Case

The prototype demonstrates how synthetic patient profiles and glucose timelines can be used to explore glucose patterns. It is designed for research and demonstration, not clinical decision-making.

## 12. Run Locally

Install dependencies from the project root:

```bash id="h76t0p"
pip install -r requirements.txt
```

Start the backend:

```bash id="k0r3pz"
uvicorn backend.main:app --reload
```

In a separate terminal, start the dashboard:

```bash id="q8dbk5"
streamlit run dashboard/app.py
```

- Dashboard: http://localhost:8501
- API health: http://127.0.0.1:8000/health
- API documentation: http://127.0.0.1:8000/docs

## 13. Safety and Limitations

This prototype uses synthetic demonstration data and has not been clinically validated. It must not be used for diagnosis, treatment decisions, medication dosing, or emergencies. Any future clinical application requires appropriate data governance, privacy safeguards, rigorous evaluation, external validation, and clinical assessment.
