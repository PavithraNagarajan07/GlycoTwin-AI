# GlycoTwin AI React Dashboard

Responsive React + Vite UI for the existing FastAPI backend. The design uses a deep-navy navigation rail, bright clinical workspace, teal sensor charts, purple prediction visual, clear synthetic-data labels, and a responsive layout.

## Requirements
- Node.js 20+ (Node.js 22 LTS recommended)
- GlycoTwin FastAPI running on `http://127.0.0.1:8000`
- Model and synthetic data generated by `python -m backend.train`

## Run locally
```cmd
npm install
npm run dev
```

Vite prints the local URL, normally `http://127.0.0.1:5173`. Configure a different backend with `.env` copied from `.env.example` and `VITE_API_BASE_URL`.

## Views and interactions
- **Twin overview:** synthetic EHR summary, glucose trajectory, model probability, model context.
- **Live simulator:** replays the latest 384 synthetic readings sequentially and requests historical model estimates at intervals. This is a replay demo, not a live wearable connection.
- **Model evaluation:** displays actual saved evaluation metrics and explains rare-event pitfalls.
- Patient switcher, API refresh, JSON snapshot export, responsive layout, API error handling.

## Safety
All included data are synthetic. Predictions are experimental and are not intended for diagnosis, treatment, medication dosing, or emergency monitoring.
